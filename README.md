# Remember Save Fix — Welcome to the Game II

Wi-Fi password fix for loaded saves in Welcome to the Game II (WTTG2). Add-on for Epic Remember Networks.

**Скачать:** [готовые файлы](https://github.com/x1pee/wttg2-remember-save-fix/releases/tag/v1.0.0).

Дополнение к Epic Remember Networks 1.0.0. Восстанавливает связь с ранее сохранёнными паролями после загрузки того же мира по BSSID и типу защиты. Не открывает неизвестные пароли; противоречивые записи пропускаются. Оригинальный Epic_RememberNetworks.dll нужен и остаётся отдельной зависимостью.

## Установка и использование

Скачайте ZIP из Releases. Закройте игру и скопируйте `WTTG2RememberSaveFix.dll` в `BepInEx/plugins`. Запустите игру снова. Для отката удалите эту DLL при закрытой игре.

Установите оригинальный Epic Remember Networks отдельно, затем добавьте WTTG2RememberSaveFix.dll в plugins. Подключение остаётся ручным: пароль подставляется, кнопку Connect нажимаете вы. Отключение — удалить только DLL дополнения при закрытой игре.

## Исходники и сборка

Сборка требует локальные игровые библиотеки и BepInEx 5.4.23.5; они не включены в репозиторий.

```powershell
.\build.ps1 -GamePath "D:\Games\Welcome to the Game II"
```

Для сборки этого дополнения также нужен Mono: передайте `-MonoPath "D:\Mono"`. Опция `-Test` запускает тесты на искусственных данных.

## Проверка

22 проверки политик и реального writer/parser на искусственных данных; проверены текущий сейв, старый идентификатор и перезапуск изолированной копии. Все сценарии сторонних менеджеров сохранений не проверены.

Проверено на Windows x64, Unity 2017.3. Для BepInEx-плагинов используется BepInEx 5.4.23.5. Совместимость с другими версиями игры не гарантируется.
